## 08.10: trzy kierunki do wyboru (research poszerzony o katalogi eventowe i sportowe: Spartan/Tough Mudder, Hipcamp, Ironman, Songkick, Red Bull Events, Outdooractive, Eventbrite)
- **A "Dziennik z gór"** (`home.html`, `kalendarz.html`, `bieg.html`): papier, serif, lista miesiącami, kafelki dat. Inspiracje: gotrail, komoot, Outside.
- **B "Eksplorator"** (`b_eksplorator.html`): pasek wyszukiwania jak Hipcamp, chipy szybkich filtrów jak Songkick ("ten weekend", "ten miesiąc"), lista z lewej + mapa pełnej wysokości z prawej jak Spartan/Ironman, "za 2 dni · 52 km od Ciebie" przy każdym biegu, karta wybranego biegu na mapie.
- **C "Nocny plakat"** (`c_plakat.html`): ciemne tło, kondensowany display (Bebas), wielkie numery dni jak plakaty, siatka kart-plakatów z sylwetką pasma, pasek "najbliżej" jak ticker. Inspiracje: Red Bull Events, Dice, plakaty biegowe.
